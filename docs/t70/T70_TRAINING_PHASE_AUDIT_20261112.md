## 4. 重点风险与解释

**问题A：无效动作惩罚产生大量“全同终局奖励但仍非零 Advantage”的PG信号。**

直接反序列化Step1真实树，256题中122题的所有终局正确性奖励相同，其中112题由于不同轨迹的无效动作惩罚产生了非零Advantage。此类题贡献约547898个非零Advantage Token，占全部非零Advantage Token（957626）的57.2%。原因是先扣减0.01×无效动作次数再做组内标准化，即使原始惩罚小，标准化后贡献也不一定小。此为**代码按设计运行，但可能改变训练信号重心**的风险；目前只建议保留日志观察，不在正式训练中临时改损失。

**问题B：OPSD的梯度非常弱。**

首步诊断文件 `diagnostics/gradient-step1.json` 显示 PG梯度范数0.317273，已乘0.1系数的KD梯度范数0.001087，KD/PG=0.003427（即0.343%），余弦-0.0226。这是首Mini-batch的一个KD优先Micro-batch，非整步平均。说明新OPSD确实是弱辅助，但在当前强度下是否仍有可测贡献尚不能确认。Step1与2的 `kd/to_pg_loss_abs_ratio` 分别仅0.000340与0.000128，是**损失数值比**而非梯度范数比。不要混淆。

**问题C：成功SFT强度尚未独立量化。**

SFT系数0.05，Step1/2成功Token很多（142918/120410），平均Token CE约0.722/0.709。独立SFT梯度范数缺少测量，因此不能仅看系数就断言它一定弱于或强于PG。

**问题D：关键管理链路和最终评估尚未经过真实运行。**

Reflector/Utility管理每5 Step触发，在Step1/2为0属正常；需重点观察Step5。Step10首次运行内Dev1000复测；Step50首次Test6125。当前不能声称经验有效、长期稳定或泛化提升。
